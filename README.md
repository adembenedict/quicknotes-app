# QuickNotes App

QuickNotes is a clean, lightweight, and responsive web application designed for capturing, organizing, and searching short personal, work, and study notes directly in the browser.

## Features

- **Add Categorized Notes:** Create notes tagged as Personal, Work, or Study.
- **Form Validation:** Prevents empty submissions and enforces a 200-character limit with instant error feedback.
- **Real-Time Search:** Instant case-insensitive filtering of stored notes.
- **Persistent Storage:** Saves notes locally using `localStorage` so content survives browser refreshes.
- **Dynamic Count:** Displays grammatically correct note totals (`0 notes`, `1 note`, `N notes`).
- **Responsive Card Layout:** Mobile-friendly Flexbox design with distinct visual category borders.
- **Clear All Option:** Enables full note deletion with safety confirmation prompts.
